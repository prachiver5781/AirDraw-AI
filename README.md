# AirDraw AI 🎨

A real-time virtual drawing application that allows users to draw in the air using hand gestures and computer vision.

## 🚀 Features
- ✍️ Air drawing using index finger
- 🧽 Gesture-based eraser
- 🎨 Neon brush effects
- ⚡ Real-time hand tracking
- 🖐️ Gesture-controlled settings
- 🧼 Full palm to clear screen


## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- MediaPipe Hands
- p5.js

## 🎮 Gesture Controls

| Gesture | Action |
|---------|---------|
| ☝️ Index Finger Up | Draw |
| ✌️ Index + Middle Finger | Eraser |
| ✊ Fist | Stop |
| 🖐️ Full Palm | Clear Canvas |
